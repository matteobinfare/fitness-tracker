# FitTrack - Your Personal Fitness Companion 💪

A beautiful, feature-rich fitness tracking app built with React. Track your strength training, cardio, body weight, and progress over time.

## Features

✨ **User Authentication** - Secure login with registration code
💪 **Strength Training** - Log 72+ exercises organized by muscle group
🏃 **Cardio Tracking** - Track running, cycling, rowing, swimming, and more
⚖️ **Body Weight Progress** - Monitor your weight with beautiful trend charts
📊 **Analytics** - Visualize your progress with advanced charts and statistics
🌙 **Dark Mode** - Easy on the eyes with optional dark theme
📱 **Mobile Optimized** - Works perfectly on iPhone, Android, and desktop
💾 **Local Storage** - All data saved privately on your device

## Getting Started

### Local Development

1. Clone the repository:
```bash
git clone https://github.com/yourusername/fitness-tracker.git
cd fitness-tracker
```

2. Install dependencies:
```bash
npm install
```

3. Start the development server:
```bash
npm start
```

4. Open [http://localhost:3000](http://localhost:3000) in your browser

### Default Registration Code

When creating a new account, use the registration code: **pennypasta**

## Deployment

This app is deployed on Netlify and updates automatically when you push to GitHub.

### Deploy on Netlify

1. Push your code to GitHub
2. Go to [netlify.com](https://netlify.com)
3. Click "New site from Git"
4. Select your repository
5. Build settings (auto-detected):
   - Build command: `npm run build`
   - Publish directory: `build`
6. Click "Deploy site"

Once deployed, you can add the app to your iPhone home screen:
1. Open the Netlify URL in Safari
2. Tap Share → Add to Home Screen
3. App appears on your home screen like a native app

## Technology Stack

- **React 18** - UI framework
- **Recharts** - Data visualization
- **Lucide React** - Icons
- **LocalStorage** - Data persistence

## Privacy

All your data is stored locally on your device. Nothing is sent to external servers (except the app hosting on Netlify).
